# DriveGuard Lab Frontend

This directory contains the React, TypeScript, and Vite foundation for the
DriveGuard Lab interface. The current page is informational only and does not call
the backend.

## Commands

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run test
npm.cmd run build
```

On systems where PowerShell permits `npm.ps1`, `npm` can be used in place of
`npm.cmd`.
